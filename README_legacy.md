# MANIT TeamUp

A dedicated campus collaboration and teammate discovery Android application for **Maulana Azad National Institute of Technology (MANIT Bhopal)**.

## Overview
MANIT TeamUp empowers students, developers, designers, and innovators across departments at MANIT Bhopal to:
- Discover teammates for Hackathons (Smart India Hackathon, internal hackathons), coding competitions, academic projects, and startup ideas.
- Filter by technical skills (AI/ML, Web, Mobile, Blockchain, IoT, UI/UX, Cloud, Robotics) and branches (CSE, IT, ECE, EE, Mech, Civil, Chem, MSME, Arch, M.Tech/MCA/MBA).
- Verify scholars using institutional `@stu.manit.ac.in` and `@manit.ac.in` credentials with automatic Scholar ID badge detection.
- Send collaboration requests, join teams, create rosters, and connect directly via WhatsApp and campus networks.

## Technology Stack
- **Platform:** Android (minSdk 24, targetSdk 35)
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **State Management:** MVVM Architecture with Kotlin StateFlow & Coroutines
- **Build System:** Gradle (Kotlin DSL `.gradle.kts`) with Version Catalog

## How to Build & Run
1. Clone this repository or open the project folder.
2. Open with **Android Studio** (Ladybug or newer) or **Google Antigravity**.
3. Allow Gradle to sync dependencies automatically.
4. Run on an Android device or emulator running API 24+ (Android 7.0 Nougat or higher).
